# Halo · Modèles Office

Modèles Word, PowerPoint et Excel du design system Halo, dans douze nuances.

Le site : choisir une nuance, puis télécharger le document déjà réglé (couverture, couleurs, Helvetica).
Le pack complet (`pack/`) contient les modèles .dotx/.potx/.xltx en français et en anglais, les 12 thèmes Office,
les jeux de couleurs et un installateur pour Mac.
